# Restored project structure

The preferred project identity and legal/evidence context are restored. This is an integration of the earlier research workbench and the later practical evidence-comparison tool, not a replacement by a different product.

- About the project: Same Decision, Different Reasons; why this matters; proposed use.
- Inspect a decision: measured comparison-group, local-approximation and external-score evidence; optional local import. The research model predicts a repayment label; it does not reconstruct an actual lender decision.
- Compare results: detailed versus grouped reason changes, sampling sensitivity, approximation fidelity and upstream-score dependence. The masked-change example links to a retained measured record and matched sampling seed.
- Review findings: an actual session record combining numerical evidence with reviewer interpretation, evidence request, responsible owner and next action. Readable and JSON exports preserve those distinctions. No outbound request is sent.
- Legal requirements: adverse action versus discriminatory effects; current framework separation; requirements/evidence/method table; alternative-method comparison; CFPB, NYDFS and Tech Sprint examples; responsibility and source status.
- Research design: methods, data, protocol history, limitations, implementation identity, literature and reproduction.

No artificial wording dictionary is used by the main interface. Earlier constructed-notice checks remain supplementary reproducible work.

The added grouping summary is an exploratory descriptive analysis of already generated reference explanations. It measures up to four positive signed factors/categories after aggregation. It is not a new preregistered confirmation, an independent user study, or a rate of incorrect actual notices. The original model and explanation outputs remain unchanged.
